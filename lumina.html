달의 요정 · 파일 관리자

Lumina Archive 루미나 아카이브 v0.1.0

달빛이 스며드는 서고에서 요정 루미나가 파일을 지키고 정리해 주는 파일 관리자 겸 뷰어예요. 파일과 파일 정보는 폰 밖으로 나가지 않아요. 인터넷은 광고에만 써요.

APK 내려받기 릴리즈 노트

달빛 서고를 둘러봐요

폴더는 서가, 파일은 서가에 꽂힌 기록이에요. 루미나가 정리하고, 열람실에서 바로 펼쳐 읽어요.

서가 둘러보기

내장 저장소와 SD 카드의 모든 폴더를 목록·격자로 보고, 이름·크기·날짜·종류로 정렬해요.

파일 작업

복사·이동·이름 바꾸기·삭제·공유. 이름이 겹치면 건너뛰기·덮어쓰기·둘 다 두기를 골라요. 긴 작업은 앱을 닫아도 알림에서 이어져요.

달 그림자 (휴지통)

지운 파일은 정해 둔 기간(7·30·90일) 동안 보관했다가 되살릴 수 있어요.

달의 서고 (홈)

저장 공간을 달의 위상으로 보여 주고, 카테고리·별자리(즐겨찾기)·최근 파일을 모아 봐요.

등불 검색

저장소 전체에서 파일 이름을 찾아요. 종류·크기·날짜로 거를 수 있어요.

달빛 열람실

텍스트(큰 로그·한글 인코딩 자동 감지), JSON 트리, 코드 강조, Markdown, 이미지, PDF, ZIP 안 보기. 다른 앱에서 "Lumina로 열기"도 돼요.

압축

ZIP 만들기·풀기. 한글 파일 이름 ZIP도 깨지지 않아요.

달 뒤편의 서고

패턴·지문으로 잠그는 AES-256 암호화 보관함. 복구 코드로 다시 열 수 있어요.

미리보기 버전이라 요정 마을(다른 요정 앱과의 연계)은 아직 없어요.

알아 두세요

상태
첫 공개 미리보기 (v0.1.0)
지원 기기
Android 8.0 (API 26) 이상
권한
파일 관리자라서 "모든 파일 액세스"를 요청해요. 거부하면 고른 폴더만 쓰는 제한 모드로 동작해요.
광고
GitHub 배포판에는 홈 화면에 광고가 하나 있어요. 광고 제거는 Play 스토어 판에서만 살 수 있어요.
복구 코드
비밀 서고의 복구 코드는 꼭 따로 보관해 주세요. 잃어버리면 아무도 파일을 되살릴 수 없어요.
