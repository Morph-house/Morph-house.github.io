Wisp 위스프

메신저 알림을 받아 자동으로 답장하는 봇 앱이에요. JavaScript로 스크립트를 써서 명령어 응답, 공지 전달, 시간 재기 같은 동작을 직접 만들 수 있어요. 밤길의 도깨비불처럼, 대화방 한쪽에서 조용히 불을 밝힙니다.

이런 걸 할 수 있어요

JavaScript 봇

ES6 문법의 API2와, 기존 봇 스크립트를 그대로 옮겨 올 수 있는 레거시 API를 모두 지원해요.

폰에서 바로 편집

자동 들여쓰기, 괄호 닫기, 찾기·바꾸기를 갖춘 편집기. 태블릿에서는 목록·편집·뷰어 세 칸으로 펼쳐져요.

테스트룸

실제 대화방에 보내기 전에, 가상의 메시지로 스크립트 동작을 먼저 시험해요.

로그와 콘솔

받은 메시지·보낸 메시지·실행 로그를 거르고 검색해요. 실행 중인 전역 변수도 들여다볼 수 있어요.

시작 순서 관리

스크립트끼리 의존하는 순서대로 자동 정렬하고, 재부팅 뒤에도 그 순서대로 미리 컴파일해요.

홈 화면 위젯

전체 컴파일, 전체 켜기·끄기, 최근 메시지를 홈 화면에서 바로 다뤄요.

무한루프 방지

CPU 시간으로 10초 넘게 도는 스크립트를 멈춰서, 스크립트 하나가 봇 전체를 멈추지 않게 해요.

다섯 가지 테마

밤하늘, 새벽, 저녁 노을, 숲, 바다. 별이 흐르는 배경 애니메이션은 끌 수도 있어요.

스크립트는 이렇게

// 명령어 "더하기 2 3" 에 답하는 봇
const bot = BotManager.getCurrentBot();

bot.addListener("command", (msg) => {
    if (msg.command === "더하기") {
        const sum = msg.args.map(Number)
                            .reduce((a, b) => a + b, 0);
        msg.reply("합계는 " + sum + " 이에요");
    }
});

테스트룸

더하기 2 3

합계는 5 이에요

더하기 10 20 30

합계는 60 이에요

처음 시작하기

  1. 권한 허용 알림 접근, 모든 파일 접근, 배터리 최적화 제외 세 가지를 허용해요.
  2. 프로젝트 만들기 + 버튼으로 프로젝트를 만들고 API를 골라요. API2를 권장해요.
  3. 스크립트 쓰기 + 스크립트로 파일을 만들고 코드를 적어 저장해요.
  4. 컴파일 오류가 있으면 그 줄로 바로 이동해요.
  5. 켜고 시험하기 테스트룸에서 확인한 뒤, 실제 메신저에서 메시지를 보내 봐요.

PC에서도, Wisp Desktop

폰에서 쓰기엔 긴 스크립트라면 PC용 Wisp Desktop을 써 보세요. 코드 편집기, 자동 완성, 콘솔, 디버거를 갖춘 데스크톱 도구로 Wisp 스크립트를 PC에서 쓰고 시험할 수 있어요.
